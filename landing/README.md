# Goulash.tech — лендинг под сегмент «служба доставки со своей курьеркой»

Тестовый лендинг этапа 1: один сегмент, один оффер, живое демо продукта и мок-форма заявки.
Приложение изолировано в папке `landing/` и не затрагивает Figma-плагины в корне репозитория.

Стек: Next.js 16 (App Router), React 19, Tailwind CSS 4, TypeScript. Шрифт Onest и акцент
`#00FFFF` — по базовой айдентике Goulash.tech 2023.

## Запуск

```bash
cd landing
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшен-сборка
npm run lint
```

## Что внутри

| Путь | Что это |
|---|---|
| `app/page.tsx` | сборка лендинга из секций: герой, боль, роли, демо, цифры, кейсы, модули, переход, тарифы, FAQ, заявка |
| `components/shift-demo.tsx` | интерактивное демо смены: тумблер «как сейчас / на Гуляше», роли, фильтр типов курьеров, ручное назначение, стоп-лист |
| `lib/shift.ts` | данные демо-смены и логика: автораспределение, ETA, KPI |
| `components/lead-form.tsx` | форма заявки: валидация, состояние загрузки, успех, ошибка |
| `app/api/lead/route.ts` | мок-эндпоинт заявки |
| `promo/render.mjs` | сборка промо-креативов под VK, Telegram, Яндекс и ОК |

## Промо-креативы

Креативы собираются кодом, чтобы текст оставался редактируемым, а типографика — фирменной:

```bash
npm run promo                # рендерит PNG в promo/out
CHROME_PATH=/path/to/chrome npm run promo
```

Форматы: 1080×1080 (VK, ОК), 1080×1920 (VK Клипы, сторис), 1080×607 (Яндекс РСЯ), 1280×720
(пост в Telegram), 600×600 (тизер ОК).

## Проверка сценариев

- **Демо смены** — переключите режим «Как сейчас» / «На Гуляше»: пересчитываются среднее время
  доставки, опоздания, нераспределённые заказы и потери. Отключение типа курьеров (пеший, вело,
  авто) меняет распределение, вкладки ролей — сам экран, стоп-лист на вкладке «Кухня» —
  уведомление и статусы заказов.
- **Форма** — пустая отправка показывает ошибки полей; корректные данные дают загрузку и экран
  «Заявка отправлена»; телефон, оканчивающийся на `0000`, возвращает экран ошибки.

Данные демо-смены придуманные. Цифры в маркетинговых блоках — с goulash.tech и из открытых
источников, форма заявки никуда не отправляет данные.
